POAbooth website package

This folder is ready for static website hosting.

To get a public website link:
1. Open https://app.netlify.com/drop
2. Sign in or create a Netlify account.
3. Upload this ZIP file (or drag the extracted folder) to the page.
4. Netlify will publish the site and provide a public URL.

Open the generated URL to use POAbooth. Camera access requires HTTPS and permission from the browser.
